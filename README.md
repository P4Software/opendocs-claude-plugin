# OpenDocs plugins for Claude

This repository is a Claude plugin marketplace with one plugin, [`opendocs`](plugins/opendocs/README.md): skills for writing, organizing and publishing documentation to [OpenDocs.cloud](https://opendocs.cloud) from Claude.

Add it in Claude Code:

```
/plugin marketplace add glenntosco/opendocs-claude-plugin
/plugin install opendocs@opendocs
```

Or in claude.ai: Customize > Plugins > Add > Add marketplace, with this repository URL.
